# Domain: agent_architecture

## Purpose
Collects architecture and operational knowledge for the NC Medicaid policy agent, including memory setup, toolchain, and response guardrails.

## Scope
Included in this domain:
- Agent bootstrapping (model selection, tool wiring)
- Memory configuration and storage requirements
- Policy-specific system prompts, guardrails, and citation rules

Excluded from this domain:
- General Mastra product tutorials
- Non-policy agents or unrelated services

## Ownership
NC Medicaid Agent team

## Usage
Reference for onboarding new contributors to the agent and for auditing policy response rules.
