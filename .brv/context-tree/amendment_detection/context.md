# Domain: amendment_detection

## Purpose
Capture knowledge about how graph-based pipelines detect DHHS amendment relationships for Medicaid documentation.

## Scope
Included in this domain:
- Document scanning heuristics for change notices and revised SPAs
- Context extraction and signal section identification logic
- Graph edge creation and status updates for AMENDS relationships

Excluded from this domain:
- General document ingestion unrelated to DHHS amendments
