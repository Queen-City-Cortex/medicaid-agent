# Domain: auth_integration

## Purpose
Capture integration-specific knowledge for authentication libraries that require deployment-specific overrides or fixes.

## Scope
Included in this domain:
- Deployment adjustments for auth libraries
- Edge cases when hosting under Docker/Railway
- Environment variable mappings for auth callbacks

Excluded from this domain:
- General authentication architecture
- User-facing authentication docs

## Ownership
Platform Infrastructure

## Usage
Use this domain for documenting deployment-unique authentication fixes, host overrides, and environment nuances.
