# Domain: evaluation

## Purpose
Provides a central reference for quality evaluation pipelines that score answers and verify references for the Medicaid Navigator.

## Scope
Included in this domain:
- Answer scoring procedures (Level 3)
- Cross-reference verification (Level 2)
- Neo4j evidence and document relationships
- Agent invocation strategies and failure handling

Excluded from this domain:
- Business logic unrelated to evaluation scoring
- General agent runtime configuration

## Ownership
Evaluation Engineering Team

## Usage
Use this domain to document evaluation flows, scoring heuristics, and instrumentation relevant to QA metrics.
