# Domain: frontend_ui

## Purpose
Holds knowledge about frontend UI layout behaviors, particularly scroll handling and sidebar stability in the web application.

## Scope
Included in this domain:
- ScrollArea and viewport scrolling behaviors
- Layout overflow rules that affect sibling elements
- Chat UI layout adjustments that touch scrolling or sidebar rendering

Excluded from this domain:
- Backend APIs or agent stream logic unrelated to UI layout
- Generic design tokens without layout impact

Web Frontend Team
