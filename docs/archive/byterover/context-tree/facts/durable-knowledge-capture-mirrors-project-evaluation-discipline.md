# Durable knowledge capture mirrors project evaluation discipline

facts and agent_architecture both describe knowledge management as a structured pipeline rather than chat notes. The facts domain requires recon, extraction, UPSERT-first curation, and verification via applied file paths, while agent_architecture’s curated_context workflow preserves structured facts instead of raw output. This makes durable knowledge capture operate under the same rigor as the project’s evaluation and validation systems.

## Evidence

- **facts**: The curation contract is recon → extraction → curate → verify, with UPSERT-first updates and verification based on applied results rather than rereading source files.
- **agent_architecture**: The durable context workflow preserves structured facts and treats curation as operational knowledge management rather than transient chat history.
- **evaluation**: Evaluation quality depends on aligned datasets, explicit graph relationships, and careful handling of edge cases, showing the same emphasis on provenance and verification.
