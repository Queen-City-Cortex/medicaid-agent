# Domain: qa

## Purpose
Capture end-to-end testing patterns and helpers for the Medicaid navigator agent UI.

## Scope
Included in this domain:
- Playwright configuration for mocked and smoke suites
- Test helpers that mock Mastra streaming and memory APIs
- Page objects for chat interactions and thread sidebar
- Guidance on running and extending e2e tests

Excluded from this domain:
- Unit or integration tests outside the Playwright harness
- Backend service implementation details

## Ownership
QA/Automation Team

## Usage
Document any updates to Playwright suites, helper utilities, and page abstractions used by e2e tests.
