## Stopping point — assessment

Stopped after 2 refactors by design, not exhaustion. The codebase was already heavily refactored (last ~8 commits). rerank was the standout structural issue (graph's least-cohesive large cluster). Remaining candidates deliberately NOT done:
- **agent/index.ts CLI-runner extraction** — reasonable, but the agent package has ZERO tests and the runtime needs API keys + Neo4j, so it cannot be live-tested here. Skipped to honor "live-test after each step." (Observation for the user: agent package has no test suite — a real gap, but adding one is a separate task, not a refactor.)
- **query analysis / frame builders / coverage-sections** — refactored in the last 1–3 commits; re-touching = churn.
- **pipeline get_session() → CorpusRepository** — would create a huge *shallow* god-repository coupling unrelated domains. Wrong direction.
- **value-type wrappers / fluent builders / strategy registries / shared.ts sub-barrels / answer-frame-planning file split** — over-engineering or cosmetic churn over irregular domain logic.
