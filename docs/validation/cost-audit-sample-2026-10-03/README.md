# Corpus cost audit and small usage sample — October 3, 2026

This work starts from current main and preserves the two pending embedding implementations. It audits retained artifacts without changing source payloads, parsed outputs, graph contents or production model selections. The live sample is a private cost diagnostic against the selected legacy graph, not release qualification or a model migration experiment.

The parser currently renders every declared Excel column, including trailing blank columns introduced by formatting. The largest sampled DRG workbook declares 16,383 columns on its first sheet but stores values only through column seven. Six large spreadsheet artifacts are measured with pinned local Voyage tokenization before and after diagnostic trailing-empty-cell trimming. Occupied serialized cell values and their row/column positions must match exactly. Duplicate payloads/versions are inventoried separately and never automatically removed.

The six-question sample uses existing benchmark IDs q-001, q-004, q-006, q-012, q-030 and q-048. It covers simple lookup, cross-document, multi-hop, negative-answer and federal-reference cases. GPT-5.4 generates answers; Terra verifies exact outgoing text. It invokes no judge, research, browser or observational-memory evaluation. Database/diagnostics paths are isolated. The runner operates on a private copy of the checkout and disables server response storage in that copy, so subsequent model requests carry explicit bounded context. This diagnostic differs from production storage behavior and is not an acceptance test. A sample-only gateway reserves estimated worst-case cost durably before every provider request, caps cumulative commitments at $5 and 64 requests, forces standard processing, bounds output at 8,192 tokens and rejects implicit stored contexts, built-in tools and oversized inputs. Unknown usage and failed/timed-out requests retain their reservations; successful measured usage can release the unused reservation. The child receives placeholder provider keys; real keys stay in the gateway. External model calls must pass through the gateway.

Scripts: [artifact audit](../../../scripts/ops/audit-corpus-cost.py), [sample runner](../../../scripts/ops/run-cost-sample.py), [finite gateway](../../../scripts/ops/sample-budget-gateway.py), and [child fetch routing](../../../scripts/ops/sample-budget-preload.mjs). Run only against a frozen checkout with matching locked dependencies, an absolute private output directory and private selected service settings. Keep raw drafts and evidence private. Provider token usage repriced at verified standard rates estimates usage cost (Terra uncached inputs conservatively include a 25% cache-write ceiling); it is not an invoice. Small samples and output/context limits do not qualify the full campaign.

## Findings

The [audit](audit-summary.json) covers 1,726 retained fee-schedule parsed artifacts; sidecars mark 1,701 ready, including 984 spreadsheets. Readiness here is an artifact annotation, not proof of current registry or graph membership. Spreadsheet text falls from 2,640,526,669 to 257,579,947 characters in the diagnostic: **90.2% less text**, with all occupied serialized cell signatures preserved. The [original workbook dimensions](workbook-dimensions.json) confirm the cause: the DRG sheet declares `A1:XFC808` (16,383 columns) but has stored values only through column seven; the sampled physician sheets declare 702 columns but have values only through seven. Source workbook formatting inflated the declared dimensions, and `parse_xlsx`/`parse_xls` renders every blank cell before joining rows.

Six intentionally selected large artifacts drop from 105,763,325 to 4,766,094 pinned local tokens: **95.5% fewer tokens**. The same diagnostic planner reduces embedding inputs from 17,578 to 677. Their headings are diagnostic basenames/titles, not the complete graph context. This is not a full post-repair corpus estimate. The retained artifact inventory also finds 92 identical-source groups and 64 identical spreadsheet-body groups. Different URLs, dates and versions can still carry distinct provenance; automatic deletion is unwarranted. Original payloads, parses and graph content were untouched.

## Completed live sample

[Sample receipts](sample-summary.json) and the [budget ledger](budget-ledger.json) record **six questions, 39 provider requests and approximately $0.52** in provider-token usage cost. Every request returned usage; no uncertainty debit remains. Four final answers passed verification directly; two were corrected and passed on the second verification. Those outcomes do not replace an independent judge or full release acceptance. The sample uses the selected live legacy graph, whose [release marker and counts remained stable](graph-preservation.json). Its historical embedding provenance remains unproven; these are cost observations, not model/graph quality comparisons.

Generation used 149,987 input tokens across 18 requests: about **25,000 total input tokens per question**, versus the earlier 100,000 assumption. Verification used 73,778 across eight passes: about **12,300 per question**, versus the earlier 80,000 assumption. Generation averaged 768 output tokens; verification averaged 481 per question. CLI skips chat scope/injection classifiers and observational memory, so that web overhead is unmeasured. Private storage-disabled requests and an 8,192-output-token cap also differ from production. The child had no real provider key; all funded requests passed through the finite gateway.

The [revised scenario](revised-cost-scenario.json) extrapolates the sampled workload across 378 answers/scope cases, retains the earlier $24.75 judge and separate retrieval assumptions, and gives **$57.41 with observed caching or $66.53 with cached-input discounts removed**. This replaces the former roughly $232 evaluation assumption for planning purposes only. With the unchanged archived corpus embedding estimate, totals are **$172.58–$181.70**. The corpus was not compacted or re-embedded, so no cheaper full-corpus total is claimed. Six deliberately chosen questions do not establish a statistically representative workload, enforce a full-campaign cap or qualify the candidate. No paid judge, research, browser or memory acceptance occurred.

Raw answers, diagnostics and failed-attempt receipts were retained in an encrypted, append-only [evidence object](evidence-publication.json); downloading the object verified its ciphertext SHA-256. Decryption was not tested in this task. The [temporary sample directory was removed](sample-cleanup.json) after matching the local and remote ledger/manifest hashes. The source corpus and shared application files were preserved.
