## Embedding repair

The shared planner preserves original body slices, includes contextual headings in the 9,000-character input limit, bounds overlap to 512 characters and checks exact pinned local Voyage token counts against 32,000 tokens. It splits again when needed. Setup and Docker provision SHA-verified tokenizer assets; runtime never downloads them implicitly. Bounded batches accelerate local counting with four tokenizer workers. The provider client rejects oversized individual/batch requests before transport and sends `truncation=false`.

Generation preflights the entire graph before mutations or provider calls. Plan hashes bind exact input text, offsets, model, dimensions and tokenizer policy. Incomplete or changed plans are replaced atomically; matching missing vectors resume. Semantic document revisions bind content and complete heading ancestry. Loader changes invalidate section and chunk vectors, while timestamp-only refreshes preserve them. Planning and result writes lock the owner section and reject a changed revision or missing target. Reload unversioned source graphs before generating embeddings. Release coverage requires complete saved plans with matching revisions and vector dimensions.

Context reads page ten IDs and stream one Bolt record at a time. Audit-only preparation writes a fresh `audit-<run-id>` subdirectory and identifies the original build separately, preserving its receipts. [Review dispositions](review-dispositions.json) explain the fixes and the intentional bounded federal-response read.
